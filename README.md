# 小一練功房

小學一年級的數學、注音、時鐘錢幣與國字練習。純靜態網頁，**完全離線可用**，沒有後端、沒有外連資源、沒有任何資料上傳。

**線上版：https://graylightai.github.io/grade1-drill/**

手機用 Safari 或 Chrome 開，「分享 → 加入主畫面」就是全螢幕、鎖直板的 app。

## 數學怎麼教

小孩學加減會經過「全部數 → 接著數 → 推導 → 直接提取」四個階段，前三個都不算會。
所以這裡做了三件事：

- **十格板**：答錯時給的不是文字，是圖。8 個點放上去，剩 2 格空的一眼就看見
- **部分－整體圖**：7 分成 3 和 4。`3+4=7`、`4+3=7`、`7-3=4`、`7-4=3` 是同一件事的四種寫法
- **減法教成「還差多少」**：13-8 不是往回數 8 次，是「8 還差多少到 13」，直接接上湊十

加上反應時間判定（答對但超過 6 秒不升箱），整套都在對付「停不下用數的」這件事。

## 核心：它不隨機出題

一般練習 app 隨機抽題，結果八成時間在練小孩已經會的東西。這裡用間隔重複（Leitner）：

| 情況 | 處理 |
|---|---|
| 答錯 | 掉回第 0 箱，**這一輪稍後再出一次**，今天與明天都還會出現 |
| 答對且夠快（≤ 6 秒） | 升一箱，間隔拉長成 1 → 2 → 4 → 8 → 16 天 |
| **答對但很慢** | **不升箱，明天就回來**——還在扳手指就不是真的會 |

「弱點診斷」頁按細項列出熟練度與反應時間中位數，告訴家長她卡在**哪一個數字、哪一組符號**，而不是只給一個分數。

## 題庫

1276 個知識點，每一個獨立追蹤：

| 科目 | 知識點 | 內容 |
|---|---|---|
| 數學 | 148 | 湊十、10 以內加法、進位加法、退位減法、**還差多少**、**算式家族**、比大小、數序 |
| 注音描寫 | 37 | 描 37 個注音符號（真實字形，**不做筆順**，見下） |
| 注音 | 300 | 拼讀選圖、看圖拼注音、聲調、形近符號辨別（直式注音） |
| 時鐘 | 72 | 認到五分、**認到一分**、**再過多久**、**幾分鐘前**（不出整點） |
| 國字 | 418 | **筆順描字**（186 字）、**數筆畫**（212 字）、形近字辨別 |
| 英文 | 254 | **大小寫對應**（52）、看圖選單字、看單字選圖、開頭字母 |
| 混色 | 13 | 兩個顏色混在一起會變成什麼色（顏料的減法混色） |
| 色階 | 21 | 同一個色相 4／5／6 階，**拖曳**排成由淺到深 |
| 圖形邏輯 | 13 | **找規律**（AB/ABC/AAB/ABB × 形狀或顏色）、**旋轉接續**、**2×2 矩陣** |

注音**全部做成視覺題，不需要任何聲音**——這樣離線百分之百可靠，也不依賴裝置有沒有裝中文語音包。

## 檔案

```
index.html      整個 app
img/            129 張圖＋app 圖示（與目力練功房共用）
strokes.json    212 個一年級常用字的筆順資料
fonts/          自帶拉丁字體，中文走系統字體
sw.js           Service Worker，負責離線
build-sw.py     改完東西跑這支重新產生 sw.js
```

## 離線

連著網路開一次，Service Worker 會把 138 個檔案（約 1.1 MB，含筆順資料）全部抓進快取。之後從主畫面點開完全不需要網路。

> 改過 `index.html` 或 `img/` 之後**一定要跑 `python3 build-sw.py` 再 commit**，
> 否則已經裝在主畫面的 app 會一直吃舊快取。

本機測試要起伺服器（`file://` 下 Service Worker 不會註冊）：

```
python3 -m http.server 8000
```

## 筆順描字

`strokes.json`（435 KB）是從 Make Me a Hanzi 的 `graphics.txt`（30 MB、9574 字）裁出來的
212 個一年級常用字，含每一筆的輪廓路徑與中線。

- 田字格 + 整字淡底，當前筆畫紅色高亮、起筆位置有紅點
- 「看一次怎麼寫」用 SVG mask 沿著筆畫中線把輪廓一點一點露出來
- 手指寫完一筆就比對：重新取樣 16 點算平均距離，另外檢查起筆位置與方向
- 連錯三次自動播一次示範
- 用過示範或錯太多就不算熟，這一題會再回來

**筆順標準的差異：**這份資料沿用中國大陸的筆順規範。絕大多數字跟教育部標準一致，
少數字（例如「方」「出」「比」）順序不同。要對筆順請以學校教的為準，這裡是熟練用的。
app 的「家長須知」裡也寫了這一點。

## 注音描寫：為什麼不做筆順

Make Me a Hanzi 只收漢字，**37 個注音符號一個都沒有**（已查證），
目前也沒有其他開源的注音筆順資料集。

曾經試過兩條路，都不可靠：

1. **憑記憶手描** — 超過三分之二是錯的（ㄅㄉㄋㄌ 都畫成「刀」、ㄓ 畫成「乙」、
   ㄑㄍ 少筆畫）。已整個丟掉。
2. **從字形自動骨架化推筆畫** — 毛刺與交叉點處理不乾淨，ㄠ 推出 14 筆、ㄕ 推出 1 筆。

所以改成**只做描寫、不做筆順**：

- 字形取自 **Noto Sans TC**（SIL OFL）的真實輪廓，37 個全部正確，不是我畫的
- 她用手指把整個符號描過去，**不要求順序**
- 評分用覆蓋率：把字形切成 48×48 格，`isPointInPath` 問瀏覽器哪些格在字裡面，
  再比對她畫過的格子。覆蓋 ≥70% 且出界 ≤25% 才算過
- 容錯：字形往外膨脹 2 格當容錯帶（手指比筆畫粗）；覆蓋判定也放寬 1 格
  （小孩是沿筆畫中間畫線，不會塗滿）
- 實測 37/37 中線描寫通過，37/37 亂畫被擋下

**要加筆順的話，資料給我就行**：她習字本或《國語注音符號手冊》上的筆順，
我編進去，程式架構已經有了（國字那套就是逐筆的）。

## 眼睛

近距離作業一樣要顧：手機拿在 30 公分左右，設定裡可調休息提醒間隔，到時會跳出 20 秒看遠倒數。
字級以**看得舒服**為準——護眼是靠距離和休息，不是靠把字縮小。
